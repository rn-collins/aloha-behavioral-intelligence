# Screen culture → testable behavior hypotheses

An issue-spotting layer for exploring screen-culture attention signals and testable consumer-behavior hypotheses.

**Live:** https://aloha-behavioral-intelligence.vercel.app

## Repository contents

`package-lock.json`, `package.json`, `pages`, `public`, `styles`, `vercel.json`

## Local development

```sh
npm ci
npm test
npm run build
```

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
